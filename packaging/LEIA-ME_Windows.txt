LimpaIA para Windows
====================

O que faz
---------
Remove dos JPEGs o selo de "feito com IA" (Content Credentials / C2PA) sem
recomprimir a foto. Autoria, copyright, Exif e perfil de cor são mantidos.
Seus originais NÃO são alterados: as cópias limpas ficam numa subpasta chamada
JPEG_SEM_METADATA_IA, com os mesmos nomes, junto de um relatório.

Funciona no Windows 10 e 11. Não precisa instalar nada nem ser administrador.


Jeito mais fácil: um comando, sem aviso do SmartScreen
------------------------------------------------------
Abra o PowerShell (Menu Iniciar, digite PowerShell e tecle Enter), cole a
linha abaixo e tecle Enter:

  irm https://github.com/alberthpalhares/limpaia/releases/latest/download/install.ps1 | iex

Ele baixa o LimpaIA, confere se o arquivo veio íntegro, instala para o seu
usuário, cria o atalho no Menu Iniciar e o item "Remover metadados de IA" no
botão direito. Instalado assim, o Windows não mostra "O Windows protegeu o seu
PC": pule para "Usar". (O "Controle Inteligente de Aplicativos" do Windows 11,
se estiver ligado, continua bloqueando; veja abaixo.)
Para atualizar, rode o mesmo comando. Para remover:

  $env:LIMPAIA_REMOVER=1; irm https://github.com/alberthpalhares/limpaia/releases/latest/download/install.ps1 | iex

Se preferir usar o LimpaIA.exe baixado, veja abaixo.


Primeira abertura (uma vez só)
------------------------------
O LimpaIA é gratuito e não tem assinatura digital paga. Por isso, ao abrir o
LimpaIA.exe pela primeira vez, o Windows pode mostrar "O Windows protegeu o
seu PC". Isso é esperado: o programa não acessa a internet e não altera seus
originais. Para liberar:

  1. Clique em "Mais informações".
  2. Clique em "Executar assim mesmo".

Ao baixar pelo Edge ou Chrome, o navegador também pode avisar "não é baixado
com frequência": escolha "Manter" e depois "Manter assim mesmo". Enviar o
programa dentro de um .zip costuma reduzir esse aviso.

Se o aviso nem deixar abrir: botão direito no LimpaIA.exe > Propriedades >
marque "Desbloquear" na parte de baixo > OK. Depois abra de novo.

Windows 11 com "Controle Inteligente de Aplicativos" ligado: ele bloqueia
programas sem assinatura e não oferece botão para liberar. Só dá para usar
desligando-o em Segurança do Windows > Controle de aplicativos e navegador >
Configurações do Controle Inteligente de Aplicativos (depois de desligado,
não dá para ligar de novo sem reinstalar o Windows).

Se o antivírus mover o arquivo para a quarentena, restaure-o e adicione uma
exceção para o LimpaIA.exe (antivírus às vezes desconfiam de programas novos
e sem assinatura).


Usar
----
Dê dois cliques no LimpaIA.exe. Na primeira vez, ele pergunta se você quer
adicionar "Remover metadados de IA" ao menu do botão direito: responda "Sim"
(recomendado). Depois abre uma janela para escolher a pasta com os JPEGs, e ao
terminar a pasta de resultado abre sozinha.

Usando o menu: clique com o botão direito numa pasta (ou no fundo de uma
pasta aberta) > "Remover metadados de IA". No Windows 11 fica em "Mostrar
mais opções". Processa todos os JPEGs daquela pasta de uma vez.

O menu usa uma cópia do programa em %LOCALAPPDATA%\LimpaIA, então você pode
mover ou apagar o LimpaIA.exe baixado depois de instalar o menu.

Instalar o menu depois (se respondeu "Não") ou remover, no Prompt de Comando:

     LimpaIA.exe --instalar
     LimpaIA.exe --desinstalar

Também dá para arrastar uma pasta de fotos sobre o LimpaIA.exe.


Resultado
---------
Dentro da pasta processada surge JPEG_SEM_METADATA_IA com:
- as fotos limpas (mesmos nomes);
- RELATORIO_*.txt e RELATORIO_*.csv: quantas fotos tinham marca de IA, o que
  foi removido, erros e se algo permaneceu.
Publique as fotos dessa subpasta.

Remover o selo do arquivo não garante que uma rede social não detecte IA por
outros meios.
